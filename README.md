# SoccerStarsApp – C# Console Game Project

SoccerStarsApp is a C# console-based application developed as part of my software development and gameplay systems projects. The project focuses on gameplay logic, structured functionality, user interaction, and debugging within a modular console environment.

The application includes gameplay systems, menu navigation, audio integration, and interactive logic-driven features designed to simulate a simple game experience through a console interface.

## Key Areas Demonstrated

* Object-oriented programming (OOP)
* Gameplay and logic system design
* Input handling and validation
* Debugging and troubleshooting
* Modular programming structure
* Runtime file and asset management
* Structured testing and functionality verification

## Testing & QA Focus

Testing involved identifying and resolving issues related to:

* Input handling
* Gameplay flow
* Runtime file dependencies
* Logic consistency
* User interaction behaviour
* Application stability during execution

## How to Run

1. Download and extract the ZIP file
2. Open the extracted folder
3. Run `SoccerStarsApp.exe`
4. Ensure all files and folders remain within the same directory for correct functionality
